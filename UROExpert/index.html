📚 Basis Pengetahuan

Penjelasan Metode

Fungsi Massa Dasar

m{A} = belief (bobot pakar)
m{Θ} = 1 − belief (ketidakpastian)
di mana A = set penyakit terkait gejala

Aturan Kombinasi Dempster

m₁₂(Z) = ΣX∩Y=Z m₁(X)·m₂(Y) / (1−K)
K = ΣX∩Y=∅ m₁(X)·m₂(Y)

Belief & Plausibility

Bel(A) = ΣB⊆A m(B)
Pl(A) = ΣB∩A≠∅ m(B)

Bel(A) ≤ kemungkinan sebenarnya ≤ Pl(A)

Frame of Discernment (Θ)

Θ = {P01, P02, P03, P04, P05, P06}
= himpunan semua hipotesis yang mungkin
